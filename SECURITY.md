# Security policy

placekit carries a caller's Google API key to the Places API, so key handling flaws are security issues in this project.

Report a vulnerability privately through GitHub's private vulnerability reporting on this repository, under the Security tab's "Report a vulnerability" route. That keeps the report closed while it is assessed. Please do not open a public issue for a vulnerability, and never include a real API key in a report.

The latest release on PyPI is the supported line, and fixes ship in a new release on that line.
